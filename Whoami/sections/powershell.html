⚡ ¿Qué es PowerShell?

PowerShell es un shell de línea de comandos y un lenguaje de scripting diseñado para la administración de sistemas y la automatización. A diferencia de CMD, PowerShell trabaja con objetos estructurados, lo que permite un control mucho más preciso.

💡 Tip: Usa Get-Help para obtener ayuda de cualquier cmdlet.

🔑 Estructura Verbo-Sustantivo

Los comandos (cmdlets) siguen el patrón Verbo-Sustantivo:

  • Get → Recupera datos (Get-Process)
  • Set → Modifica propiedades (Set-Item)
  • Add → Agrega elementos (Add-Content)
  • Stop → Detiene (Stop-Service)
  • Start → Inicia (Start-Service)
  • Clear → Elimina elementos (Clear-Host)

Ejemplo: Get-Process → Obtiene procesos en ejecución.

📁 Gestión de Archivos y Carpetas

📂 Comandos básicos

Get-ChildItem

Lista archivos y carpetas (similar a dir / ls).

Get-ChildItem -Path C:\Logs -Recurse -Filter *.log
Básico
Copy-Item

Copia archivos/carpetas.

Copy-Item -Path C:\src\* -Destination D:\backup\ -Recurse -Force
Básico
Move-Item

Mueve o renombra elementos.

Move-Item -Path C:\temp\*.pdf -Destination D:\PDFs\
Básico
Remove-Item

Elimina archivos/carpetas.

Remove-Item -Path C:\temp\* -Recurse -Force
Básico
New-Item

Crea archivos o directorios.

New-Item -Path C:\backup -ItemType Directory
Básico
Rename-Item

Renombra un elemento.

Rename-Item -Path C:\temp\old.txt -NewName new.txt
Básico

📄 Lectura y escritura

Get-Content

Lee contenido de archivos.

Get-Content -Path C:\logs\app.log -Tail 50 -Wait
Intermedio
Set-Content

Escribe contenido en un archivo (sobrescribe).

Set-Content -Path C:\temp\report.txt -Value "Informe generado $(Get-Date)"
Intermedio
Add-Content

Añade contenido al final de un archivo.

Add-Content -Path C:\logs\access.log -Value "$(Get-Date) - Acceso permitido"
Intermedio
Clear-Content

Borra el contenido de un archivo sin eliminarlo.

Clear-Content -Path C:\temp\cache.txt
Intermedio
Test-Path

Verifica si una ruta existe.

if (Test-Path C:\temp) { Write-Host "Existe" }
Básico
