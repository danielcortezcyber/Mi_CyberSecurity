🖥️ ¿Qué es CMD?

El Símbolo del Sistema (CMD) es la interfaz de línea de comandos nativa de Windows. Es la herramienta más antigua y aún esencial para tareas rápidas, scripts heredados y diagnóstico de red.

💡 Ejecuta como Administrador: Haz clic derecho → "Ejecutar como administrador" para comandos que modifican el sistema.

⌨️ Atajos y Trucos Esenciales

F1 Copia el último comando carácter por carácter
F3 Pega el último comando completo
F5 Recorre el historial hacia atrás
F7 Muestra el historial en ventana emergente
Tab Autocompleta nombres de archivos/carpetas
Ctrl + C Detiene la ejecución de un comando
Ctrl + V Pega texto (Windows 10/11)
comando /? Muestra la ayuda integrada
comando | clip Copia la salida al portapapeles
comando && comando2 Ejecuta varios comandos en secuencia

📂 Navegación y Archivos (Básicos)

Comandos fundamentales para moverse y gestionar archivos.

📋 dir Básico

Sintaxis: dir [unidad:][ruta] [opciones]

Lista archivos y subdirectorios del directorio actual.

Ejemplos:

dir                     # Lista el directorio actual
dir /w                  # Vista compacta (varias columnas)
dir /s C:\              # Lista recursivamente todo el disco C:
dir *.txt               # Filtra archivos .txt
dir /o:s                # Ordena por tamaño (ascendente)
dir /b                  # Formato simple (solo nombres)

Parámetros clave:

  • /w → Vista ancha, varias columnas
  • /s → Incluye subdirectorios (recursivo)
  • /b → Formato simple (solo nombres, sin encabezados)
  • /o:orden → Ordena por: n (nombre), s (tamaño), d (fecha), e (extensión)
  • /p → Muestra página por página
💡 Tip: dir /s *.log busca todos los archivos .log en el disco.
📁 cd Básico

Sintaxis: cd [unidad:][ruta]

Cambia el directorio actual (Change Directory).

cd \                    # Va a la raíz del disco actual
cd ..                   # Sube un nivel
cd "C:\Program Files"   # Ruta con espacios, usa comillas
cd /d D:\               # Cambia a la unidad D: y directorio raíz
💡 Buenas prácticas: Usa cd /d para cambiar de unidad y directorio en un solo comando.
📁 md / mkdir Básico

Sintaxis: md [unidad:]ruta o mkdir [unidad:]ruta

Crea un nuevo directorio (carpeta).

md Nuevo                     # Crea carpeta "Nuevo"
md C:\Backup\2025            # Crea ruta completa (crea subcarpetas)
mkdir "Mis Documentos"       # Con espacios, usar comillas
📌 Nota: md puede crear rutas completas, a diferencia de rmdir que solo elimina directorios vacíos (a menos que uses /s).
🗑️ rmdir / rd Básico

Sintaxis: rmdir [unidad:]ruta [/s] [/q]

Elimina un directorio (carpeta).

rmdir Nuevo                  # Elimina solo si está vacío
rmdir C:\Backup\2025 /s /q   # Elimina con todo su contenido (sin confirmar)
  • /s → Elimina el directorio y todo su contenido (subdirectorios y archivos)
  • /q → Modo silencioso, no pide confirmación (usar con precaución)
⚠️ Advertencia: rmdir /s elimina permanentemente sin enviar a la Papelera. Úsalo con cuidado.
📄 copy Básico

Sintaxis: copy origen destino

Copia uno o más archivos de un lugar a otro.

copy archivo.txt D:\backup\     # Copia a una carpeta
copy *.pdf C:\PDF\              # Copia todos los .pdf
copy /y archivo.txt D:\         # Sobrescribe sin preguntar
copy /v archivo.txt D:\         # Verifica que se copió correctamente
  • /y → Sobrescribe archivos existentes sin confirmar
  • /-y → Pide confirmación antes de sobrescribir
  • /v → Verifica la integridad de la copia
🚚 move Básico

Sintaxis: move origen destino

Mueve o renombra archivos y directorios.

move doc.txt D:\Documentos\      # Mueve archivo
move antiguo.txt nuevo.txt       # Renombra archivo
move "C:\Temp\*" D:\Temp\        # Mueve todo el contenido de Temp
💡 Buenas prácticas: Usa move para renombrar archivos/carpetas de manera rápida sin copiar.
❌ del / erase Básico

Sintaxis: del [unidad:]ruta [opciones]

Elimina uno o más archivos.

del archivo.txt              # Elimina archivo
del *.tmp /s                 # Elimina archivos temporales recursivamente
erase datos.dat              # Mismo efecto que del
del /f archivo.txt           # Fuerza la eliminación (archivos de solo lectura)
  • /s → Busca y elimina en subdirectorios
  • /q → Modo silencioso (no pide confirmación)
  • /f → Fuerza la eliminación de archivos de solo lectura
⚠️ Advertencia: del elimina permanentemente (no usa Papelera de reciclaje).
✏️ ren Básico

Sintaxis: ren [unidad:]ruta nombre_actual nombre_nuevo

Renombra archivos o carpetas.

ren archivo.txt nuevo.txt
ren *.jpg *.jpeg     # Cambia extensión de todos los .jpg a .jpeg
📖 type Básico

Sintaxis: type [unidad:]ruta

Muestra el contenido de un archivo de texto en la pantalla.

type readme.txt
type *.log | more    # Muestra paginado
💡 Tip: Combina con more para leer archivos largos: type archivo.txt | more.
🔧 echo / cls / exit / help / ver / date / time / title / color / prompt Básico

Ejemplos:

echo Hola Mundo
cls                             # Limpia la pantalla
exit                            # Cierra la ventana
help dir                        # Muestra ayuda del comando dir
ver                             # Versión del sistema operativo
date                            # Muestra y permite cambiar la fecha
time                            # Muestra y permite cambiar la hora
title "Servidor"                # Cambia el título de la ventana
color 0A                        # Fondo negro, texto verde
prompt $p$g                     # Muestra la ruta actual en el prompt

Colores (color):

  • 0 Negro, 1 Azul, 2 Verde, 3 Aguamarina, 4 Rojo, 5 Púrpura, 6 Amarillo, 7 Blanco
  • 8 Gris, 9 Azul claro, A Verde claro, B Aguamarina claro, C Rojo claro, D Púrpura claro, E Amarillo claro, F Blanco brillante

📦 Manipulación Avanzada de Archivos

Herramientas para copias masivas, búsquedas avanzadas y manipulación de archivos.

📋 xcopy Intermedio

Sintaxis: xcopy origen destino [opciones]

Copia archivos y directorios con más opciones que copy.

xcopy C:\src D:\dest /E /I /H   # Copia todo (subdirectorios, ocultos, sistema)
xcopy C:\src D:\dest /E /C       # Continúa incluso si hay errores
xcopy C:\src D:\dest /U          # Copia solo archivos que ya existen en destino
  • /E → Copia subdirectorios, incluso vacíos
  • /I → Si destino no existe, crea como directorio
  • /H → Copia archivos ocultos y del sistema
  • /C → Continúa a pesar de errores
  • /Y → Sobrescribe sin preguntar
  • /Z → Modo de reinicio (útil para redes inestables)
🔄 robocopy Avanzado

Sintaxis: robocopy origen destino [archivos] [opciones]

Herramienta de copia robusta para sincronizar directorios (más potente que xcopy).

Ejemplos:

robocopy C:\src D:\dest /MIR      # Sincroniza espejo (borra lo que sobra en destino)
robocopy C:\src D:\dest /E /ZB /R:3 /W:10  # Copia con reintentos
robocopy C:\src D:\dest /MIR /XF *.tmp    # Excluye archivos .tmp
  • /MIR → Espeja la estructura (borra archivos extras en destino)
  • /E → Copia subdirectorios, incluso vacíos
  • /ZB → Usa modo de reinicio en archivos abiertos
  • /R:n → Número de reintentos
  • /W:n → Tiempo de espera entre reintentos (segundos)
  • /XF → Excluye archivos (por extensión o patrón)
  • /XD → Excluye directorios
💡 Buenas prácticas: Usa robocopy para backups y sincronización, ya que reanuda copias interrumpidas y maneja archivos abiertos.
🔒 attrib Intermedio

Sintaxis: attrib [+r | -r] [+a | -a] [+s | -s] [+h | -h] [unidad:]ruta [/s] [/d]

Muestra o cambia los atributos de archivos.

attrib +h secret.txt          # Oculta el archivo
attrib -r -s boot.ini         # Quita solo lectura y sistema
attrib +h +s carpeta /d       # Oculta carpeta con atributo de sistema
  • +r/-r → Agrega/Quita solo lectura
  • +a/-a → Agrega/Quita atributo de archivo
  • +s/-s → Agrega/Quita atributo de sistema
  • +h/-h → Agrega/Quita atributo oculto
  • /s → Recursivo en subdirectorios
  • /d → Aplica a directorios
🔍 find Intermedio

Sintaxis: find "cadena" [unidad:]ruta [opciones]

Busca una cadena de texto en archivos (versión simple).

find "error" log.txt
find /i "usuario" usuarios.txt   # Búsqueda insensible a mayúsculas
find /n "2025" *.log             # Muestra el número de línea
  • /i → Insensible a mayúsculas/minúsculas
  • /n → Muestra el número de línea
  • /v → Muestra líneas que NO contienen la cadena
🔎 findstr Avanzado

Sintaxis: findstr "patrón" [unidad:]ruta [opciones]

Busca cadenas usando expresiones regulares (como grep).

findstr "error" *.log
findstr /s /i "usuario" C:\*.txt
findstr /v "ok" archivo.log   # Líneas que NO contienen "ok"
findstr /r "^\d{4}" *.log    # Líneas que empiezan con 4 dígitos
  • /s → Busca en subdirectorios
  • /i → Insensible a mayúsculas
  • /v → Muestra líneas que NO coinciden
  • /r → Usa expresiones regulares
  • /l → Busca literalmente (sin regex)
  • /m → Muestra solo el nombre del archivo si hay coincidencia
💡 Tip: findstr es ideal para auditoría de logs y búsquedas complejas en archivos de texto.
🔀 fc / comp Intermedio

Sintaxis: fc archivo1 archivo2 [opciones] o comp archivo1 archivo2

Compara archivos y muestra diferencias.

fc archivo1.txt archivo2.txt
fc /b imagen1.bmp imagen2.bmp   # Comparación binaria
comp archivo1 archivo2          # Comparación byte a byte
📊 more / sort / tree Intermedio 
more archivo.txt                # Muestra página por página
dir /s | more                   # Salida paginada
sort nombres.txt /o ordenados.txt  # Ordena alfabéticamente
tree C:\Proyectos               # Muestra estructura de directorios

🌐 Red y Conectividad

Herramientas para diagnosticar, configurar y administrar redes.

🌐 ipconfig Intermedio

Sintaxis: ipconfig [opciones]

Muestra la configuración de red (IP, máscara, puerta de enlace, DNS).

ipconfig                 # Información básica
ipconfig /all            # Detalles completos (MAC, DHCP, etc.)
ipconfig /release        # Libera la IP DHCP
ipconfig /renew          # Renueva la IP DHCP
ipconfig /flushdns       # Limpia la caché DNS
ipconfig /displaydns     # Muestra la caché DNS
💡 Buenas prácticas: Después de cambiar la configuración de red, usa ipconfig /flushdns y ipconfig /registerdns.
📡 ping Básico

Sintaxis: ping [-t] [-n count] [-l size] [-w timeout] destino

Prueba conectividad con un host mediante ICMP.

ping google.com -n 10          # 10 pings
ping -t 192.168.1.1            # Ping continuo (Ctrl+C para detener)
ping -a 8.8.8.8                # Resuelve el nombre inverso
ping -l 1500 -f google.com     # Paquetes de 1500 bytes sin fragmentar
  • -t → Ping continuo
  • -n count → Número de pings
  • -l size → Tamaño del paquete
  • -w timeout → Tiempo de espera (ms)
  • -a → Resuelve el nombre del host
  • -f → No fragmentar (detecta MTU)
🗺️ tracert / pathping Intermedio

Sintaxis: tracert [-d] [-h max_saltos] destino y pathping destino

Rastrea la ruta hasta un destino. pathping añade estadísticas de pérdida.

tracert google.com
tracert -d google.com        # No resuelve nombres (más rápido)
pathping google.com          # Combina traceroute y ping
🔌 netstat Intermedio

Sintaxis: netstat [-a] [-n] [-o] [-b] [-e] [-p protocolo]

Muestra conexiones de red, puertos abiertos y estadísticas.

netstat -an            # Todas las conexiones y puertos (sin resolver nombres)
netstat -ano           # Incluye PID del proceso
netstat -b             # Muestra el programa que usa cada puerto
netstat -e             # Estadísticas Ethernet
💡 Tip: netstat -ano es útil para identificar procesos que están usando puertos (útil en ciberseguridad).
📇 nslookup Intermedio

Sintaxis: nslookup [nombre] [servidor_dns]

Consulta registros DNS.

nslookup google.com
nslookup 8.8.8.8              # Resolución inversa
nslookup -type=MX google.com  # Registros MX
nslookup -type=NS google.com  # Servidores de nombres
🔗 arp Intermedio

Sintaxis: arp [-a] [-d] [-s]

Muestra y modifica la tabla ARP (asociación IP-MAC).

arp -a                 # Muestra tabla ARP
arp -d                 # Borra toda la tabla
arp -s 192.168.1.10 00-AA-00-62-C6-09  # Agrega entrada estática
🛣️ route Avanzado

Sintaxis: route [print] [add] [delete] [change]

Muestra o modifica la tabla de enrutamiento IPv4.

route print
route add 192.168.0.0 mask 255.255.255.0 10.0.0.1
route delete 192.168.0.0
route change 192.168.0.0 mask 255.255.255.0 10.0.0.2
⚙️ netsh Avanzado

Sintaxis: netsh [contexto] [comando]

Herramienta de configuración de red (muy potente).

netsh int ip reset           # Reinicia la pila TCP/IP
netsh wlan show profiles
netsh wlan show networks
netsh advfirewall show allprofiles
netsh interface ip set dns "Ethernet" static 8.8.8.8
🖥️ hostname / getmac / telnet / ssh / ftp Básico 
hostname                     # Nombre del equipo
getmac /v                    # Dirección MAC de los adaptadores
telnet 192.168.1.10 80       # Prueba puerto HTTP

ftp ftp.ejemplo.com          # Cliente FTP
⚠️ Advertencia: Telnet transmite credenciales en texto plano. Usa SSH siempre que sea posible.

🔧 Guía de Resolución de Problemas

Escenarios comunes y cómo solucionarlos con CMD.

🌐 Sin conexión a Internet

  1. ipconfig /all → Verifica IP, máscara y puerta de enlace.
  2. ping 8.8.8.8 → Si falla, problema de cable/router. Si funciona, problema DNS.
  3. nslookup google.com → Si falla, cambia DNS: netsh interface ip set dns "Ethernet" static 8.8.8.8.
  4. ipconfig /flushdns → Limpia caché DNS.
  5. netsh int ip reset → Reinicia la pila TCP/IP.

🔒 Puerto bloqueado

  1. netstat -an | findstr :80 → Verifica si el puerto está en escucha.
  2. telnet 192.168.1.10 80 → Prueba conexión desde otro equipo.
  3. netsh advfirewall firewall add rule name="HTTP-In" dir=in action=allow protocol=TCP localport=80 → Crea regla de firewall.

🐌 Equipo lento

  1. tasklist /fi "memusage gt 100000" → Identifica procesos con alta memoria.
  2. taskkill /im chrome.exe /f → Finaliza procesos problemáticos.
  3. wmic logicaldisk where drivetype=3 get deviceid, freespace, size → Verifica espacio en disco.
  4. chkdsk C: /f → Programa reparación de disco.

🔑 Olvidé contraseña de usuario local

  1. net user → Lista usuarios locales.
  2. net user usuario * → Cambia contraseña (necesita Admin).
  3. net user usuario /logonpasswordchg:yes → Forzar cambio en próximo inicio.

📁 Error de acceso a carpeta compartida

  1. net share → Verifica si el recurso está compartido.
  2. icacls C:\carpeta → Revisa permisos NTFS.
  3. net stop server /y → Reinicia servicio de red.
  4. ping nombre-pc → Verifica resolución de nombres.

❌ "Acceso denegado" al ejecutar comando

  1. Ejecuta CMD como Administrador.
  2. takeown /f C:\ruta\archivo → Toma propiedad.
  3. icacls C:\ruta\archivo /grant Administradores:F → Concede permisos.

🕵️ Conexiones salientes inusuales

  1. netstat -ano | findstr ESTABLISHED → Lista conexiones establecidas.
  2. tasklist | findstr [PID] → Identifica proceso.
  3. taskkill /pid [PID] /f → Finaliza proceso sospechoso.

🖥️ Windows no inicia

  1. Arrancar en modo reparación y abrir CMD.
  2. sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows
  3. dism /Image:C:\ /Cleanup-Image /RestoreHealth
  4. bootrec /fixmbr /fixboot /rebuildbcd

📚 Recursos Adicionales

  • Comando /? → Ayuda integrada para cualquier comando.
  • Microsoft Docs → Documentación oficial de comandos de Windows.
  • SS64.com → Referencia completa de comandos CMD.
  • Scripting en CMD → Aprende a crear archivos .bat para automatizar tareas.

✅ Buenas Prácticas

  • Siempre prueba en un entorno de desarrollo antes de ejecutar comandos destructivos en producción.
  • Usa /? para recordar sintaxis y opciones.
  • Guarda la salida de los comandos para auditoría y diagnóstico: comando > log.txt
  • Ejecuta como Administrador solo cuando sea necesario.
  • Documenta tus scripts con comentarios (REM).
  • Usa @echo off al inicio de scripts .bat para limpiar la salida.
