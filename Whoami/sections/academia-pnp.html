Prácticas Policía Nacional del Perú

Como practicante de TI en la Policía Nacional del Perú, te enfrentarás a un entorno real con servidores, switches, routers, firewalls y equipos de usuarios. Este módulo te prepara para los problemas más comunes que encontrarás en tu día a día.

🏛️ Infraestructura Tecnológica

  • Servidores: Windows Server, Linux (CentOS/Ubuntu), virtualización con VMware o Hyper-V.
  • Redes: Switches Cisco, routers MikroTik o Cisco, firewall Fortinet o PFSense.
  • Almacenamiento: NAS, SAN, backups en cinta o en la nube local.
  • Puestos de trabajo: Windows 10/11, aplicaciones internas (SIGE, SIDPOL, etc.).

🛠️ Problemas más comunes

  • 🔴 Caída de servidor (no responde)
  • 🔴 Problemas de conectividad de red
  • 🔴 Lentitud en aplicaciones
  • 🔴 Acceso no autorizado o malware
  • 🔴 Falla en backup / recuperación de datos
  • 🔴 Conflictos de IP (duplicadas)
  • 🔴 Impresoras y periféricos no funcionan

📋 Checklist de preparación

  • ✅ Conocer la topología de red (diagrama actualizado).
  • ✅ Tener acceso a los equipos (credenciales, consolas).
  • ✅ Saber usar herramientas de diagnóstico (ping, traceroute, telnet/SSH, Wireshark).
  • ✅ Tener a mano comandos básicos de Cisco y Linux.
  • ✅ Conocer el procedimiento para reportar incidentes.
  • ✅ Tener copia de seguridad de las configuraciones críticas.
  • ✅ Saber cómo acceder a la documentación interna (wiki, manuales).
  • ✅ Tener contacto de los responsables de cada área (servidores, redes, seguridad).
